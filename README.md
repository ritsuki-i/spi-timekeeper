# SPI Timekeeper

SPI の演習で、1問あたりの制限時間を意識して解くためのシンプルなタイマーアプリです。  
ブラウザで以下の URL を開くと使えます。

https://ritsuki-i.github.io/spi-timekeeper/

## 概要

- 問題数と1問あたりの制限時間を設定して開始できます
- 円形リングと中央のタイマー表示で残り時間を確認できます
- 0秒を超えた後も、超過時間を色付きリングで追跡できます
- 最後に各問題の所要時間と差分を一覧で確認できます

## 画面構成

### Setup Screen

開始前に以下を設定します。

- `total-questions`: 問題数
- `per-question-time`: 1問あたりの制限時間（秒）

### Timer Screen

- 現在の問題番号を表示
- 中央に `mm:ss` 形式のタイマーを表示
- 外周リングで残り時間または超過時間を表示
- `次の問題へ` で次の問題に進行
- `一時停止` で pause / resume

### Result Screen

- 合計時間
- 平均時間
- 設定時間との差分合計
- 各問題ごとの所要時間と差分

## タイマー表示

### 通常時

- 緑のリングが残り時間に応じて減少します
- 残り15秒以下で警告色に切り替わります
- 残り5秒以下で赤になります

### 超過時

- 1周目の超過は赤
- 2周目の超過は青
- 3周目以降の超過は紫
- タイマー中央の文字色もリング色に連動します
- 前の周回色を消さず、その上から次の色を重ねる構成です

## キーボード操作

- `Space`: 開始 / 次の問題へ / もう一度チャレンジ
- `Enter`: 一時停止 / 再開
- `Esc`: リセット確認

## 実装メモ

- HTML / CSS / JavaScript をすべて `index.html` にまとめたシングルファイル構成です
- タイマー更新は `setInterval(..., 1000)` を使っています
- 円形リングは SVG の `circle` と `stroke-dasharray` / `stroke-dashoffset` で制御しています
- 結果データは `state.results` に蓄積し、終了時に集計表示します

## 使い方

1. `https://ritsuki-i.github.io/spi-timekeeper/` を開く
2. 問題数と1問あたりの制限時間を入力する
3. 開始ボタン、または `Space` で開始する
4. 問題を解きながら `Space` またはボタンで次へ進む
5. 最後に結果画面でペースを確認する
