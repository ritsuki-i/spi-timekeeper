# SPI Timekeeper

SPI の演習で「1問あたりの制限時間」を意識して解くための、シングルファイル構成のタイマーアプリです。  
`index.html` をブラウザで開くだけで動作します。

## 概要

- 問題数と1問あたりの秒数を入力して開始できます
- 各問題ごとに円形タイマーと中央のカウント表示で残り時間を確認できます
- 0秒を超えた後も、超過時間をリング表示で追跡できます
- 各問題の所要時間と設定時間との差分を最後に一覧で確認できます

## 画面構成

### 1. Setup Screen

開始前に以下を設定します。

- `total-questions`: 問題数
- `per-question-time`: 1問あたりの制限時間（秒）

`startApp()` が呼ばれると設定値を読み取り、タイマー画面へ切り替わります。

### 2. Timer Screen

トレーニング中のメイン画面です。

- 現在の問題番号をバッジで表示
- 中央に `mm:ss` 形式のタイマー表示
- 外周リングで残り時間または超過時間を表示
- `次の問題へ` ボタンで次の問題に進行
- `一時停止` ボタンで pause / resume

### 3. Result Screen

全問題終了後に以下を表示します。

- 合計時間
- 平均時間
- 設定時間との差分合計
- 各問題ごとの所要時間と差分

## タイマー表示の仕様

### 通常時

- 緑のリングが残り時間に応じて減少します
- 残り `15秒超` は通常色
- 残り `5秒超` は警告色
- 残り `5秒以下` は赤色

### 超過時

超過後は追加リングで時間超過を表現します。

- 1周目の超過は赤
- 2周目の超過は青
- 3周目以降の超過は紫
- タイマー中央の文字色もリング色に連動します
- 前周の色を消さず、上から次の色を重ねる構成です

実装上は `overrun-ring` / `overrun-ring-second` / `overrun-ring-third` の3レイヤーで管理しています。

## キーボード操作

- `Space`: 次の問題へ
- `Enter`: 一時停止 / 再開
- `Esc`: リセット確認

## 実装メモ

- HTML / CSS / JavaScript をすべて `index.html` にまとめたシングルファイル構成です
- タイマー更新は `setInterval(..., 1000)` を使用しています
- 円形リングは SVG の `circle` と `stroke-dasharray` / `stroke-dashoffset` で制御しています
- 結果データは `state.results` に蓄積し、終了時に集計表示します

## ファイル構成

```text
spi-timekeeper/
├─ index.html
└─ README.md
```

## 使い方

1. `index.html` をブラウザで開く
2. 問題数と1問あたりの秒数を入力する
3. 開始ボタンを押す
4. 問題を解きながら `Space` またはボタンで次へ進む
5. 最後に結果画面でペースを確認する
